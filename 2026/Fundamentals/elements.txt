=========LangGraph/Langchain===========
- Is a state for building, managing, and deploying long-running, stateful agents.

======State========
- Is the shared data structure that holds the current information
or context of the entire application.
--> SImple Terms: It is the application's memory, keeping track
of the vairables and data that nodes can access and modify as they
execute.


=====Node========
- Individual functions or operations that perform specific tasks within
the graph.
- Each node receives input(current graph state), processes it, and
produces an output or an updated state.

======Graph======
- Is the overarching structure that maps out how different tasks(nodes)
are connected and executed.
- It visually represents workflow, showing sequence and conditional paths
between various operations.


=====Edges==========
- COnnection between nodes and determine the flow of execution.
- Tells us which node should be executed next after the current one
completes its task.

======COnditional Edges=========
- Decide the next node to execute based on specific conditions or logic
applied to the current state.


=======Start==========
- This node marks where the workflow begins.
- DOesnt perform any operations itself

======ENd============
- This node signifies the conclusion of the workflow in LangGraph.

=====Tools==========
- Specialized utilities/functions that nodes can use to perform a specific
taks, e.g fetching data from an API.
- Enhance capabilities of nodes by providing additional functionalities
- Nodes are part of the Graph while tools are functionalities used
withing nodes. 

======ToolNode======
- Special node whose main job is to run a tool.
- COnnects the tools output back to the state so other nodes can use
the information.


========StateGraph==========
- Used to compile and build the graph  structure.
-Ensures workflow operates unified.

========Runnable==========
- A runnable is a std executable component that performs a specific
task within an AI workflow.


======MESSAGES========
----Human Message--------
* Input from the user

---AI Message------
* Represents responses generated by AI models.

---System Message-----
* Used to provide instructions or context to the model

---Function Message----
* Represents the result of a function call

---Tool Message--------
* Specific to tool usage
